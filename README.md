# Smart Elephant Intrusion Prediction - Mobile App

This is the mobile application component for the **Action Prediction of Wild Elephant Attacks Using Artificial Intelligence with Smart IoT and Machine Learning**. Built using Flutter, this app serves as the primary user interface for farmers to monitor their cultivation areas, receive real time alerts, and view AI driven predictions regarding potential wild elephant intrusions.

## 📱 Features

Based on the project's use cases and system architecture, the app includes the following features:

*   **User Authentication:** Secure login and registration for farmers (integrated with Firebase Authentication).
*   **Farm Dashboard:** A centralized view to monitor active IoT sensor statuses and recent activity.
*   **Real Time Alerts:** Push notifications triggered when the IoT sensors and AI engine detect a high risk of elephant intrusion.
*   **Analytics & Predictions:** Visual representation of historical movement patterns and AI generated intrusion risk predictions.
*   **Weather Integration:** Fetches and displays current weather data via external Weather APIs to provide context to the monitoring dashboard.
*   **Profile Management:** Manage user details, update farm locations and configure notification preferences.

## 🛠️ Technology Stack

*   **Frontend Framework:** [Flutter](https://flutter.dev/) (Dart)
*   **Backend Services:** Firebase (Authentication, Realtime Database/Firestore)
*   **Push Notifications:** Firebase Cloud Messaging (FCM)
*   **IoT & Cloud Integration:** Connects to the central cloud storage layer that processes data from the LoRa enabled ESP32 sensor nodes.
